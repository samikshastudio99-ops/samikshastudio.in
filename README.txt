To publish it online:
1. Extract the ZIP.
2. Open https://app.netlify.com/drop in a browser.
3. Sign in if prompted, then drag the extracted folder (or the folder containing index.html and assets) into the upload area.
4. Netlify will publish the site and show you a public website URL.
